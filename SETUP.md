# Подключение базы данных и почты

Сайт работает в двух режимах:

- **Демо-песочница**: кнопки «Сотрудник / Руководитель / Администратор» на странице входа. Данные живут только в браузере, общую базу не трогают.
- **Рабочий режим**: регистрация по почте, общая база Supabase, письма с подтверждением, сбросом пароля и уведомлениями.

Чтобы включить рабочий режим, нужно один раз выполнить шаги ниже (около 20 минут). Всё бесплатно.

---

## 1. Supabase: база и вход по почте

1. Зайдите на https://supabase.com → **Start your project** → войдите через GitHub.
2. **New project**: имя `otp-mania`, регион **Central EU (Frankfurt)**, придумайте пароль базы и сохраните его.
3. Когда проект создастся: слева **SQL Editor** → **New query**.
   Откройте файл [`supabase/schema.sql`](supabase/schema.sql), скопируйте его целиком, вставьте и нажмите **Run**.
   Должно появиться `Success. No rows returned`.
4. Слева **Authentication** → **URL Configuration**:
   - **Site URL**: `https://artem670.github.io/otp-mania/`
   - **Redirect URLs** → **Add URL**: `https://artem670.github.io/otp-mania/`
5. **Authentication** → **Sign In / Providers** → **Email**: включено, **Confirm email** включено.
6. Слева **Project Settings** → **API Keys** (или **Data API**). Скопируйте два значения и пришлите их в чат:
   - **Project URL** (вида `https://abcdxyz.supabase.co`)
   - ключ **anon public**

   Эти два значения публичные: они и так попадут в код сайта, защиту делают правила в базе.
   **Не присылайте** ключ `service_role` и пароль базы.

## 2. Brevo: отправка писем

Встроенная почта Supabase отправляет письма только участникам проекта, поэтому для настоящих пользователей нужен почтовый сервис. Brevo бесплатно отправляет до 300 писем в день и не требует своего домена.

1. Зарегистрируйтесь на https://www.brevo.com.
2. **Senders, domains & dedicated IPs** → **Senders** → **Add a sender**: имя `ОТП Мания`, ваша почта. Подтвердите её по письму.
3. **SMTP & API**:
   - вкладка **SMTP**: запишите **Login** и нажмите **Generate a new SMTP key**, сохраните ключ;
   - вкладка **API Keys**: **Generate a new API key**, сохраните ключ.

Эти ключи секретные. Вводите их сами в Supabase, в чат их присылать не нужно.

## 3. Письма для входа (подтверждение и сброс пароля)

В Supabase: **Authentication** → **Emails** → **SMTP Settings** → **Enable Custom SMTP**:

| Поле | Значение |
|---|---|
| Sender email | почта, подтверждённая в Brevo |
| Sender name | ОТП Мания |
| Host | smtp-relay.brevo.com |
| Port | 587 |
| Username | Login из Brevo |
| Password | SMTP key из Brevo |

Там же, во вкладке **Templates**, замените тексты писем на русские.

**Confirm signup**, тема `Подтвердите почту в ОТП Мании`:

```html
<h2>Добро пожаловать в ОТП Манию!</h2>
<p>Чтобы закончить регистрацию, подтвердите почту:</p>
<p><a href="{{ .ConfirmationURL }}">Подтвердить почту и войти</a></p>
```

**Reset password**, тема `Восстановление пароля ОТП Мании`:

```html
<h2>Новый пароль для ОТП Мании</h2>
<p>Перейдите по ссылке и задайте новый пароль:</p>
<p><a href="{{ .ConfirmationURL }}">Задать новый пароль</a></p>
<p>Если вы не запрашивали сброс, просто проигнорируйте письмо.</p>
```

## 4. Уведомления на почту

Письма о начислениях РуКоинов, благодарностях, заказах и сборах отправляет сама база. В **SQL Editor** выполните, подставив свои значения:

```sql
insert into private.settings (key, value) values
  ('brevo_api_key', 'ВАШ_API_KEY_ИЗ_BREVO'),
  ('sender_email',  'почта_подтверждённая_в_brevo@gmail.com'),
  ('site_url',      'https://artem670.github.io/otp-mania/')
on conflict (key) do update set value = excluded.value;
```

## 5. Стать администратором

1. Откройте сайт, зарегистрируйтесь, подтвердите почту и войдите хотя бы раз.
2. В **SQL Editor** выполните:

```sql
select public.make_admin('ваша@почта.ru');
```

После обновления страницы появится раздел «Администрирование». Остальным ролям руководителя и администратора назначает администратор в разделе «Сотрудники и роли».

## Как это устроено

- Таблица `docs` хранит все данные приложения; при первом входе первого пользователя она заполняется стартовыми данными (демо-коллеги и история), чтобы рейтинг и аналитика не были пустыми.
- Читать данные могут только вошедшие пользователи. Роли, настройки программы, подразделения и новости меняет только администратор: это проверяет сама база, обойти через браузер нельзя.
- Изменения других пользователей подтягиваются каждые 15 секунд и при возвращении на вкладку.
- Ограничение прототипа: балансы пересчитываются в браузере, поэтому при одновременных действиях двух людей над одной записью может сохраниться последнее. Для промышленной версии расчёты переносятся в функции базы.
- Письма с отправителем на gmail.com иногда попадают в «Спам». Надёжнее подтвердить в Brevo собственный домен.
